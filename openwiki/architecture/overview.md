# Architecture Overview

This repository is organized into modular core services and testing components:

- **Calculator (`src/calculator.py`)**: Handles arithmetic computations with error handling for division by zero.
- **User Service (`src/user_service.py`)**: Manages in-memory user creation and retrieval.
- **Tests (`tests/test_calculator.py`)**: Validates core functionality.
